Privacy Policy

DOLIDE stores configuration and generated task data locally on the user's machine unless the user deploys it elsewhere.

When a user connects TikTok or YouTube, OAuth tokens may be stored in the local configuration file so the app can publish videos on behalf of the authorized user.

The app uses connected platform APIs only for the features the user enables, such as uploading videos, reading creator information required for publishing, and preparing metadata. The app does not sell personal data.

Users can revoke platform access from their TikTok or Google account settings and remove tokens from the local configuration file at any time.

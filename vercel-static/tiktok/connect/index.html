Connect TikTok

DOLIDE uses TikTok Login Kit to let creators authorize the local desktop/web app. After authorization, the app can show the connected TikTok creator, display available privacy options, and upload a creator-approved video through the Content Posting API.

The actual OAuth callback and publishing flow run in the local DOLIDE app shown in the review demo. This public page remains available for TikTok review, terms, privacy, and integration information.

Before sending content to TikTok, the app requires the user to review the generated video, caption, hashtags, AI/synthetic media label, and privacy setting.
